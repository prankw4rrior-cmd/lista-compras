# Lista de Compras

App de lista de compras partilhada em tempo real, construída com React + Firebase + Vite.

## Deploy no Vercel (5 minutos)

### 1. Colocar no GitHub
1. Vai a [github.com](https://github.com) → **New repository**
2. Nome: `lista-compras` → **Create repository**
3. Faz upload de todos estes ficheiros (arrasta para o browser)

### 2. Deploy no Vercel
1. Vai a [vercel.com](https://vercel.com) → **Add New Project**
2. Liga ao repositório `lista-compras` do GitHub
3. Clica **Deploy** (as definições já estão corretas)
4. Em ~1 minuto tens o URL: `lista-compras-xxx.vercel.app`

### 3. Instalar no iPhone como app
1. Abre o URL no **Safari** do iPhone
2. Toca em **⬆ Partilhar** → **Adicionar ao Ecrã de Início**
3. Nome: `Compras` → **Adicionar**

A outra pessoa faz o mesmo com o mesmo URL — a lista sincroniza em tempo real!

## Desenvolvimento local
```bash
npm install
npm run dev
```
